# Results

- `raw/*.csv` — append-only raw measurements written by `run_measured.py` (never edited by hand).
- `summary/` — generated by the analysis scripts (`make analysis`).
- `environment.md` — machine/toolchain snapshot (`make env`).

## Raw CSV schema
| Column | Meaning | Unit |
|---|---|---|
| run_id, timestamp, host | identification of the row | – |
| assignment, experiment, method, language | configuration labels | – |
| n | matrix side length (n × n) | – |
| dtype | numeric type (e.g. float64) | – |
| density, representation | sparse tests: nonzero fraction and storage format | fraction / – |
| threads, workers, nodes | parallel / distributed resources | count |
| process_run | index of the OS process launch for this configuration | – |
| repetition, is_warmup | in-process repetition index; 1 = warm-up (excluded from statistics) | – |
| timer_boundary | what the timer includes (kernel, end_to_end, process_wall, ...) | – |
| time_s | measured time for that boundary | s |
| process_wall_s | wall time of the whole process (monotonic clock) | s |
| peak_rss_kib | peak resident set size of the process (GNU time %M) | KiB |
| memory_metric, memory_bytes | optional program-reported memory metric | bytes |
| status, returncode | ok / timeout / oom / error; process exit code | – |
| seed, checksum | input seed; sum of result (consumes the output) | – |
| loadavg_1m | 1-minute load average when the run started | – |
| cmd, extra_json | exact command; additional program fields (JSON) | – |
